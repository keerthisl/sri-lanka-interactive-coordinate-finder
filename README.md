# Sri Lanka Interactive Coordinate Finder

An interactive web map application for finding and displaying coordinates in Sri Lanka.

## Overview

This project provides an interactive map of Sri Lanka that allows users to click anywhere on the map to display the exact latitude and longitude coordinates. It's a simple but useful tool for geographic reference, planning, or educational purposes.

![Sri Lanka Map Preview](https://github.com/keerthisl/sri-lanka-interactive-coordinate-finder/raw/main/map_preview.png)

## Features

- Interactive map centered on Sri Lanka
- Click anywhere to view latitude and longitude coordinates
- Marker at the central point of Sri Lanka
- Clean, responsive interface
- Version information displayed on the map

## Technology

This project is built using:
- Python
- Folium (Python library for creating interactive maps)
- Google Colab (development environment)
- HTML/CSS (for styling and display)

## Getting Started

### Online Demo

You can access the latest version of the map directly at:
[https://keerthisl.github.io/sri-lanka-interactive-coordinate-finder/sri_lanka_map_find_coordinates_v1.0.0.html](https://keerthisl.github.io/sri-lanka-interactive-coordinate-finder/sri_lanka_map_find_coordinates_v1.0.0.html)

### Running Locally

1. Clone this repository:
   ```
   git clone https://github.com/keerthisl/sri-lanka-interactive-coordinate-finder.git
   ```

2. Open the HTML file:
   - Navigate to the downloaded folder
   - Open `sri_lanka_map_find_coordinates_v1.0.0.html` in any modern web browser

### Running in Google Colab

1. Open the notebook in Google Colab:
   [Open in Colab](https://colab.research.google.com/github/keerthisl/sri-lanka-interactive-coordinate-finder/blob/main/sri_lanka_map_generator.ipynb)

2. Run all cells to generate the map
3. Download the generated HTML file or view it directly in Colab

## Usage

- **View Coordinates**: Simply click anywhere on the map to display the exact latitude and longitude
- **Pan and Zoom**: Use mouse controls or touch gestures to navigate the map
- **Central Marker**: The map includes a marker at the central point of Sri Lanka for reference

## Development
